# DualSub

DualSub — веб-сервис для просмотра видеоматериалов на английском языке с одновременным отображением оригинальных и заранее подготовленных переводных субтитров.

## 3. Запуск проекта

### 3.1. Предварительные требования

Для запуска проекта необходимы:

- Git;
- Docker Desktop;
- Docker Compose.

Локальная установка Python и PostgreSQL не обязательна, поскольку приложение и база данных запускаются в Docker-контейнерах.

Для локальной разработки рекомендуется Python 3.12 и виртуальное окружение.

### 3.2. Получение проекта

Клонировать репозиторий:

```powershell
git clone https://github.com/krytoichel/dualsub.git
cd dualsub
```

### 3.3. Локальная установка зависимостей

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

### 3.4. Запуск через Docker

В корневой директории проекта выполнить:

```powershell
docker compose up --build -d
```

Docker автоматически:
- соберёт образ приложения;
- загрузит образ PostgreSQL 16;
- создаст контейнеры;
- запустит приложение и базу данных.

### 3.5. Проверка работоспособности

После запуска открыть в браузере:

http://localhost:8000/health

Ожидаемый ответ:

```json
{
  "status": "ok",
  "service": "DualSub"
}
```

Также можно выполнить автоматическую проверку:

```powershell
.\scripts\check_health.ps1
```

Для просмотра состояния контейнеров:

```powershell
docker compose ps
```

### 3.6. Остановка проекта

Для остановки контейнеров выполнить:

```powershell
docker compose down
```

Для повторного запуска без пересборки:

```powershell
docker compose up -d
```

Для удаления контейнеров вместе с данными PostgreSQL:

```powershell
docker compose down -v
```

**Внимание:** последняя команда удаляет том с данными базы данных.

## 4. Проверка запуска

Проверка работоспособности выполняется по следующему сценарию:

1. Запустить проект с помощью Docker Compose.
2. Открыть endpoint `/health`.
3. Убедиться, что сервер возвращает HTTP 200 и JSON со статусом `ok`.

### Протокол проверки

| Параметр | Результат |
|---|---|
| Дата проверки | 15.11.2026 |
| Операционная система | Windows 11 |
| Среда запуска | Docker Desktop / WSL2 |
| Проверяющий | Автор проекта |
| Проверка сборки Docker | Успешно |
| Проверка PostgreSQL | Успешно |
| Проверка `/health` | {"status":"ok","service":"DualSub"} |
| Проверка чистого клона | Ожидает проверки |

## 5. Известные ограничения

- На текущем этапе реализован минимальный HTTP-интерфейс для проверки запуска приложения.
- Подключение FastAPI к PostgreSQL пока не реализовано.
- Каталог видеоматериалов и управление субтитрами находятся на этапе разработки.
- Для полноценного просмотра видео потребуется подготовка видеоматериалов и соответствующих файлов субтитров.
