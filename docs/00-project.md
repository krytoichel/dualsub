# Паспорт проекта DualSub

## 1. Название проекта

**DualSub** — веб-сервис для просмотра фильмов и видеоматериалов с двумя дорожками субтитров.

## 2. Происхождение проекта

Проект является **собственной разработкой с нуля**. Не является форком существующего программного продукта.

## 3. Назначение и решаемая проблема

DualSub предназначен для изучения английского языка посредством просмотра фильмов и видеоматериалов в оригинальной озвучке.

Основная проблема заключается в том, что при просмотре англоязычного контента пользователю приходится выбирать между английскими субтитрами, которые помогают воспринимать оригинальную речь, и переведёнными субтитрами, которые позволяют понимать содержание видео.

DualSub решает эту проблему за счёт одновременного отображения двух дорожек субтитров: оригинальной на английском языке и заранее подготовленной дорожки с переводом.

Приложение не выполняет автоматический перевод. Обе дорожки загружаются в виде готовых файлов и синхронно отображаются во время воспроизведения видео.

## 4. Целевые пользователи и их роли

- **Гость** — просматривает каталог доступных фильмов и видеоматериалов.
- **Зарегистрированный пользователь** — просматривает видео, настраивает отображение субтитров, добавляет фильмы в избранное и сохраняет прогресс просмотра.
- **Администратор** — управляет каталогом видеоматериалов, добавляет фильмы и загружает или обновляет файлы субтитров.

## 5. Три основные функции

1. **Просмотр каталога видеоматериалов** — отображение доступных фильмов, поиск и просмотр информации о них.
2. **Воспроизведение видео с двойными субтитрами** — просмотр видео в оригинальной озвучке с одновременным отображением английской и переведённой дорожек.
3. **Управление просмотром** — настройка отображения субтитров, добавление фильмов в избранное и сохранение прогресса просмотра.

### 3. Точки входа приложения

Основной точкой входа является файл `src/dualsub/main.py`.

В нём создаётся экземпляр FastAPI с названием DualSub и определяется endpoint:

- `GET /health` — возвращает JSON с состоянием сервиса и его названием.

Приложение запускается сервером Uvicorn командой:

```bash
python -m uvicorn dualsub.main:app --host 0.0.0.0 --port 8000
```

В Docker эта команда выполняется автоматически при запуске контейнера.

### 5. Хранение данных

На текущем этапе постоянное хранение данных приложения не реализовано.

PostgreSQL 16 запускается отдельным контейнером. Для него настроен именованный Docker volume `postgres_data`, позволяющий сохранять данные базы между перезапусками контейнеров.

Приложение пока не устанавливает соединение с PostgreSQL и не выполняет операции чтения или записи.

В дальнейшем предполагается использовать PostgreSQL для хранения информации о пользователях, видеоматериалах, субтитрах, избранном и прогрессе просмотра.

### 6. Конфигурация проекта

Основная конфигурация инфраструктуры задаётся в `compose.yaml`.

В нём определены:

- параметры запуска контейнера приложения;
- параметры подключения и первоначальной настройки PostgreSQL;
- проброс портов;
- Docker volume для хранения данных базы;
- проверка готовности PostgreSQL через `pg_isready`.

Для PostgreSQL используются переменные окружения:

- `POSTGRES_DB`;
- `POSTGRES_USER`;
- `POSTGRES_PASSWORD`.

На текущем этапе параметры приложения через отдельный файл настроек или переменные окружения не настраиваются.

Используемый в Compose пароль предназначен только для локальной разработки. При подготовке реального развертывания секреты необходимо вынести в переменные окружения или другой безопасный механизм конфигурации.
